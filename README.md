# MercaTax IVU PR

Aplicación para registrar ventas diarias, calcular y separar IVU en Puerto Rico.

La fuente activa se mantiene consolidada; los builds web y nativos se generan únicamente desde el pipeline canónico del repositorio.

La identidad visual de tienda usa `app-icon-official.png` como fuente canónica aprobada y sus derivados Android, iOS y PWA deben conservar exactamente esa identidad. `logo.png` se reserva para branding dentro de la aplicación y reportes; no debe usarse como launcher/store icon.
