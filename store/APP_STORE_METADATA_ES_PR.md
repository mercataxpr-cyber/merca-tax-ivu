## Description
MercaTax IVU PR ayuda a comerciantes y pequeños negocios en Puerto Rico a mantener sus ventas y el IVU organizados desde el celular.

Con la app puedes:

- registrar ventas por negocio;
- consultar historial por periodo;
- calcular y desglosar IVU;
- ver los componentes estatal y municipal cuando corresponda;
- preparar reportes mensuales y archivos PDF;
- mantener múltiples negocios organizados;
- crear respaldos y exportaciones locales;
- iniciar una radicación o contacto por WhatsApp cuando tú decidas;
- recibir recordatorios locales si autorizas notificaciones.

Tus registros operacionales se mantienen principalmente en tu dispositivo. La versión 1.0 no requiere crear una cuenta de MercaTax IVU PR.

MercaTax IVU PR es una herramienta tecnológica de apoyo. No es el Departamento de Hacienda de Puerto Rico ni SURI y no sustituye asesoría contributiva, contable o legal profesional.

## Review notes
MercaTax IVU PR 1.0 works primarily with local device storage and does not require a user account. The native package intentionally strips the web Google Analytics bootstrap. WhatsApp/share/export actions are user initiated. The app is an independent business tool and is not affiliated with the Puerto Rico Department of Treasury or SURI.

Suggested review smoke path: open app → Register → create one sale → History → Reports → Create Report PDF → Calculator. WhatsApp can be tested without sending the prepared message.
