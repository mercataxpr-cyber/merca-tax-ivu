Política de Privacidad

Última actualización: 15 de agosto de 2026

MercaTax IVU PR es una herramienta para registrar ventas, organizar información de negocios y preparar resúmenes relacionados con IVU. Esta política cubre el sitio web y las aplicaciones móviles cuando utilizan este mismo producto.

1. Datos que introduce el usuario

La aplicación puede guardar en el navegador o dispositivo la información que el usuario registra, incluyendo nombre del negocio, municipio, número de comerciante, EIN opcional, teléfono, correo electrónico, dirección, correo de referencia para respaldo, ventas, fechas, importes, tasas y preferencias de la aplicación.

2. Almacenamiento y cuentas

La versión actual no requiere crear una cuenta de MercaTax IVU PR ni utiliza un perfil de usuario en la nube para operar. Los datos operacionales se conservan principalmente en almacenamiento local del navegador o de la aplicación. Debido a que no existe una cuenta de usuario de MercaTax IVU PR, no aplica un proceso de “eliminar cuenta”; el usuario controla los datos locales mediante las funciones de borrado, limpieza del navegador o desinstalación.

3. Backups y exportaciones

Cuando el usuario genera un backup o reporte, la aplicación crea un archivo para que el propio usuario decida dónde guardarlo o compartirlo. Un correo Gmail introducido como referencia se mantiene como dato local y no activa por sí solo una sincronización automática con Google Drive.

4. WhatsApp y servicios externos

Los botones de contacto pueden abrir WhatsApp u otro servicio externo con un mensaje preparado. El envío solo ocurre cuando el usuario decide continuar y queda sujeto a las prácticas de privacidad del servicio externo.

5. Notificaciones

Si el navegador o sistema operativo lo admite y el usuario concede permiso, la aplicación puede mostrar recordatorios relacionados con fechas de IVU. El permiso es opcional y puede revocarse desde la configuración del dispositivo o navegador.

6. Analítica del sitio web

El sitio web de MercaTax puede utilizar Google Analytics para medir uso general, rendimiento y navegación del sitio. Esa analítica puede recibir información técnica del navegador conforme a la configuración de Google Analytics y a sus propias políticas.

La aplicación nativa empaquetada para iOS y Android excluye deliberadamente el script de Google Analytics durante el proceso de materialización móvil. Por tanto, la versión nativa no debe declararse como portadora de ese SDK o script web mientras el build final preserve esa exclusión.

7. Publicidad, venta y seguimiento

La versión actual de MercaTax IVU PR no incluye un SDK de publicidad en el paquete nativo, no vende los datos de negocio registrados por el usuario y no utiliza un identificador publicitario para rastrear al usuario entre aplicaciones. Si se añaden anuncios o nuevos SDK en el futuro, esta política y las declaraciones de privacidad de las tiendas deberán actualizarse antes de publicarlos.

8. Control y eliminación de datos

El usuario puede eliminar ventas, borrar negocios, limpiar el historial y eliminar los datos locales desde la aplicación, el navegador o el dispositivo. Desinstalar la aplicación normalmente elimina su almacenamiento local del dispositivo, sujeto al comportamiento del sistema operativo y a cualquier copia que el usuario haya exportado por su cuenta.

9. Seguridad

La protección de los datos locales depende también de la seguridad del dispositivo, bloqueo de pantalla, navegador, sistema operativo y copias exportadas por el usuario. Recomendamos mantener el dispositivo actualizado y proteger cualquier backup que contenga información comercial.

10. Menores

MercaTax IVU PR está diseñado como herramienta comercial y contributiva y no está dirigido a recopilar intencionalmente información personal de menores.

11. Cambios a esta política

Podemos actualizar esta política cuando cambien las funciones, SDK, servicios, permisos o requisitos legales. La fecha de actualización se mostrará en esta página y el build final deberá verificarse contra lo declarado aquí antes de enviarse a una tienda.

12. Contacto

Para preguntas de privacidad o soporte relacionadas con MercaTax IVU PR, escribe a ayuda@mercatax.com.

Nota de publicación: la política de la tienda debe corresponder exactamente al binario sometido. Si se habilita publicidad, analítica adicional, cuentas, sincronización o un nuevo proveedor, se requiere una nueva revisión de privacidad antes del release.
