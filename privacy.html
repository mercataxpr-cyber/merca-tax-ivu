Política de Privacidad

Última actualización: 24 de agosto de 2026

MercaTax IVU PR es una herramienta para registrar ventas, organizar información de negocios y preparar resúmenes relacionados con IVU. Esta política aplica a MercaTax IVU PR en su versión web instalable y en sus aplicaciones móviles para iOS y Android.

1. Datos que introduce el usuario

La aplicación puede guardar en el navegador o dispositivo la información que el usuario registra, incluyendo nombre del negocio, municipio, número de comerciante, EIN opcional, teléfono, correo electrónico, dirección, correo de referencia para respaldo, ventas, fechas, importes, perfiles o tasas contributivas y preferencias de la aplicación.

2. Almacenamiento local y cuentas

La versión actual no requiere crear una cuenta de MercaTax IVU PR ni utiliza un perfil de usuario en la nube para operar. Los datos operacionales se conservan principalmente en almacenamiento local del navegador o de la aplicación. Debido a que no existe una cuenta de usuario de MercaTax IVU PR, no aplica un proceso de eliminación de cuenta; el usuario controla los datos locales mediante las funciones de borrado, limpieza del navegador o desinstalación.

3. Backups, reportes y exportaciones

Cuando el usuario genera un backup, reporte o archivo, la aplicación crea el contenido para que el propio usuario decida dónde guardarlo o con quién compartirlo. Un correo introducido como referencia de respaldo se mantiene como dato local y no activa por sí solo una sincronización automática con Google Drive u otro servicio remoto.

4. WhatsApp, compartir y servicios externos

Los botones de radicación, contacto o compartir pueden abrir WhatsApp, la hoja de compartir del dispositivo u otro servicio externo con información preparada. La transferencia al servicio externo solo ocurre cuando el usuario inicia la acción y decide continuar. Desde ese momento también aplican las prácticas de privacidad del servicio externo elegido.

5. Notificaciones

Si el navegador o sistema operativo lo admite y el usuario concede permiso, la aplicación puede mostrar recordatorios locales relacionados con fechas de IVU. El permiso es opcional y puede revocarse desde la configuración del dispositivo o navegador.

6. Analítica

La versión web pública puede utilizar analítica web para medir uso general y rendimiento. La aplicación nativa empaquetada para iOS y Android excluye el script de Google Analytics durante el proceso de build móvil. La versión nativa actual no utiliza ese script para recopilar analítica de uso.

7. Publicidad, venta y seguimiento

La versión nativa 1.0 de MercaTax IVU PR no incluye un SDK de publicidad, no vende los datos de negocio registrados por el usuario y no utiliza un identificador publicitario para rastrear al usuario entre aplicaciones o sitios. Si estas prácticas cambian, esta política y las declaraciones de privacidad de las tiendas se actualizarán antes de publicar la función correspondiente.

8. Datos recopilados por MercaTax

En el funcionamiento nativo actual, la información comercial y las ventas que el usuario registra permanecen en el dispositivo salvo que el propio usuario ejecute una exportación o acción externa. MercaTax no recibe automáticamente esos registros por el simple uso de la aplicación.

9. Control y eliminación de datos

El usuario puede eliminar ventas, negocios y otros datos locales desde la aplicación cuando la función correspondiente esté disponible, o mediante las herramientas del navegador o dispositivo. Desinstalar la aplicación normalmente elimina su almacenamiento local, sujeto al comportamiento del sistema operativo y a cualquier copia que el usuario haya exportado por su cuenta.

10. Seguridad

La protección de los datos locales depende también de la seguridad del dispositivo, bloqueo de pantalla, navegador, sistema operativo y copias exportadas por el usuario. Recomendamos mantener el dispositivo actualizado y proteger cualquier backup que contenga información comercial.

11. Menores

MercaTax IVU PR está diseñado como herramienta comercial y contributiva y no está dirigido a recopilar intencionalmente información personal de menores.

12. Cambios a esta política

Podemos actualizar esta política cuando cambien las funciones, servicios, permisos o requisitos legales. La fecha de actualización se mostrará en esta página.

13. Contacto

Para preguntas de privacidad o soporte relacionadas con MercaTax IVU PR, escribe a ayuda@mercatax.com.

Resumen: MercaTax IVU PR 1.0 funciona principalmente con datos locales del dispositivo. Las transferencias a servicios externos ocurren cuando el usuario inicia una acción como radicar, exportar o compartir.
